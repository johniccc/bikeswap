# bikeswap

Cele jako docker kontejner

# 1. Zastav kontejnery

docker compose down

# 2. Smaž databázový volume (to vynutí reinicializaci)

docker volume rm bikeswap_db_data

# 3. Znovu postav a spusť

docker compose up -d
