# bikeswap

Cele jako docker kontejner

v dashboardu bych udělal ikonky "zprávy", kde budou všechny důležité informace. po přihlášení si je majitel může prohlídnout a najde tam i oznámení o nalezených kolech (+ se mu ukáže popup + to bude vidět u kola samotného). Zároveň se mu oznámení o nálezu odešle do mailu, s proklikem přímo ke kolu. Prostě majitel kola bude mít stránky "svého profilu", která bude především sloužít jako dashboard jeho vlastněných kol + oznámení o nich (někde v rohu možnost nastavení účtu).

u kola přibyde tlačítko ke konverzaci, nebo tak nějak bych to viděl, ať se k toomu může kdykoliv vrátit.

u nálezce ten workflow se mi líbí.

všechny změny (nová zpráva, změna stavu kola, atd.) bych právě chtěl hlásit skrz maily, pokud si to přihlášený uživatel povolí v nastavení.

zbytek mi nejspíš sedí. Hlavní 2 věci které prostě promysli, které jsou pro mě hlavní, aby bylo:
- jednoduché nahlášení nálezu (bez potřeby registrace, zvládne to i babička)
- majiteli je v podstatě nález naservírován (nemusí ho nijak těžce hledat)
